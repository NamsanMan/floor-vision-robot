# 조명 test

로봇을 컵, 흰 책, 운동화 앞에 세워 두고 같은 자리에서 실내등만 끄고 켜며 10초씩 기록했다(01 불 끔, 02 불 켬). 로봇은 움직이지 않았다. 자리와 장면이 같고 빛만 달라야 인식이 어떻게 변하는지만 볼 수 있어서다.

| | 불 켬 | 불 끔 |
|---|---|---|
| 영상 평균 밝기 (0~255) | 115 | 1.9 |
| 정면 거리 | 컵 1.09 m, 매 프레임 잡힘 | 0.29 m, 매 프레임 |
| 1.5 m 안 바닥 비율 | 99% | 7% |
| 바닥 판정 IoU (불 켬 기준) | 1.00 | 0.06 |

불을 끄면 바닥을 거의 못 찾고, '바닥 아님은 장애물'이라는 규칙대로 화면 맨 아래부터 막혔다고 판단했다(정면 거리 0.29 m는 카메라가 볼 수 있는 가장 가까운 바닥이다). 따라서 화면 전체를 장애물로 인식한다. 부딪히지는 않지만, 주행 중이었다면 그 자리에서 움직이지 못했을 것이다. LiDAR는 빛과 상관없으니 LiDAR 높이의 장애물은 계속 피한다.

불을 켠 상태에서도 흰 책은 놓쳤다. 컵과 같은 1.09 m에 있었는데, 흰 앞면을 바닥으로 보고 경계를 책 뒤 모서리(1.5 m 밖)에 잡았다. 주행 test에서 본 흰 책의 약점과 같다.

불 끈 프레임을 소프트웨어로 15배 밝혀 같은 모델에 넣어 보면 바닥 IoU가 0.77까지 올라간다. 그래도 어두운 왼쪽 가까운 곳이 막힘으로 나와 정면 거리는 그대로 0.29 m였다. 밝기만 보정해서는 안 된다.

## 카메라 자동 노출

불을 끄면 원래 이렇게 어두운지 확인하려고, 초당 12장쯤 밝기를 재면서 불을 두 번 끄고 켰다(`ae_check.png`, `ae_test.csv`). 카메라 드라이버에는 노출이나 감도 설정이 없어서 동작으로 확인했다.

| | 직전 | 직후 | 안정 |
|---|---|---|---|
| 불 끔 (두 번) | 114 / 119 | 3.6 / 3.7까지 떨어짐 | 6.8 / 6.9 (2초 안) |
| 불 켬 (두 번) | 6.8 / 6.9 | 147 / 144까지 튐 | 119 / 115 (수십 초) |

자동 노출은 켜져 있다. 불을 끄면 2초에 걸쳐 조금 밝아지고, 불을 켜면 잠깐 과하게 밝아졌다가 천천히 내려온다. 하지만 보정 폭이 2배쯤이고, 어두워도 초당 장수가 그대로라 노출 시간을 프레임 간격보다 늘리지 않는다. 어두운 곳에서는 모델보다 이 카메라 센서가 먼저 한계에 닿는다는 것을 알았다. 로봇 앞 조명, 어둡게 만든 학습 데이터, 깊이 카메라의 IR 영상 정도를 다음에 볼 만하다(IR은 아직 확인 안 함).

이 측정의 불 끔 밝기(7)가 위 test(1.9)보다 높게 나왔다. 같은 자리라 주변 빛 차이로 보이는데 확인은 못 했다.
